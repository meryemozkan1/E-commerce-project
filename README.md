# 🛍️ Modern E-Commerce Website

[![HTML5](https://img.shields.io/badge/HTML5-markup-orange?logo=html5&logoColor=white)](https://developer.mozilla.org/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-styles-blue?logo=css3&logoColor=white)](https://developer.mozilla.org/docs/Web/CSS)
![Responsive](https://img.shields.io/badge/Design-Responsive-2ea44f)

> **🚀 [View Live Demo](https://kullaniciadiniz.github.io/E-Commerce-Website/)**

A modern e-commerce storefront built with HTML5 and CSS3, fully optimized for mobile, tablet, and desktop screens. This project brings together product showcases, collection highlights, and store information into a sleek single-page interface.

---

## 🚀 Key Features & Updates

- **Responsive Layout:** Built using Flexbox, CSS Grid, and CSS custom properties for fluid adaptation across all screen sizes.
- **Hero Section:** Clean navigation menu and striking promotional hero banner.
- **Product Cards:** Styled with high-quality product images, pricing, sale badges, and star ratings.
- **Social Proof & Blog:** Dedicated customer reviews section and latest update/blog cards.
- **Location Integration:** Embedded Google Maps area for physical store directions.
- **Comprehensive Footer:** Includes full support, shop directories, company links, and social media icons.
- **Visual Styling:** Consistent design language powered by Font Awesome icons and Google Fonts (Poppins).

> **Scope Note:** This repository contains a static frontend UI design example. It does not include backend integration, user authentication, or a functional shopping cart/checkout workflow.

---

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure and content
- **CSS3** — Responsive layout, Flexbox, Grid, and Custom Properties
- **Font Awesome 6** — Vector icons (CDN)
- **Google Fonts (Poppins)** — Typography
